Notes

  1. Tray icon.The app's symbolic icon, so the panel tints it like its neighbours. A left click shows the main window, or hides it when it is already in front; a right click opens the menu. Hovering shows "Omnidict".
  2. Tray menu.Open Omnidict; Quick lookup, which opens the popup with an empty field and names the key the desktop bound (no key text when there is none); Dictionaries and Settings, which open over the main window; Quit Omnidict, which ends the app and its quick lookup key. Ctrl+Q in the window quits as well.
  3. Closing the window.With the tray switch on, the close button hides the window and the app keeps running. The first time only, the desktop shows this notification; it never repeats.
  4. Keep running in the tray.On by default wherever the desktop has a tray (KDE Plasma, Cinnamon, Xfce, GNOME with the AppIndicator extension). Off: the tray icon goes away and closing the window quits, as in 1.0.
  5. Start at login (optional, owner to decide).Off by default. When on, Omnidict starts with the session with no window, only the tray icon. Snap and Flatpak ask the desktop's Background portal; other installs write ~/.config/autostart/com.ktechpit.omnidict.desktop.
  6. No tray.Where the desktop shows no tray icons, both switches are off and greyed with the reason, and closing the window quits as today.
