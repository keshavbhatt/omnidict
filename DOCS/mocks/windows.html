Notes

  1. Same rows as Linux, Windows words. Windows has no global-shortcut service that lets the user pick the keys, so Omnidict registers the key itself (RegisterHotKey) and the row's description no longer points at the desktop's keyboard settings. The Linux fallback row ("Where the desktop has no global shortcuts", with omnidict --popup) is not shown: the shortcut always works on Windows. Default key Ctrl+Alt+D, the same as Linux. Owner to decide: on keyboard layouts with AltGr (German, Polish, French...), Windows treats Ctrl+Alt as AltGr, so Ctrl+Alt+D can clash with typing a character on a few layouts; an alternative default is Ctrl+Shift+D or Win+Alt+D.
  2. Change... turns the key caps into a field that records the next key combination, which needs Ctrl, Alt or Win plus a key. Escape or Cancel keeps the old key; Backspace turns the shortcut off (the row then reads "No key", as in quick-lookup-no-key.html). The new key is registered at once and saved in Omnidict's settings.
  3. Taken by another app. If Windows refuses the key (another app holds it), the row says so in words with the alert mark, not colour alone, and keeps the key caps so the user sees which one. The tray menu then shows no key beside Quick lookup.
  4. Start at login uses the Store package's startup task, the way Windows expects packaged apps to start with the session: it appears under Windows Settings, Apps, Startup and in Task Manager. If the user switched it off there, Windows does not let an app switch it back on, so the switch is dimmed and the row says where to turn it on, with a link that opens that page (ms-settings:startupapps). Turning it off in Omnidict works as on Linux.
  5. The word it starts with. Windows does not let an app read the text selected in another app, so the popup starts with the word on the clipboard (copy, then press the key), as on GNOME Wayland, and with an empty field when the clipboard holds no single word. Hence "Copy a word in any app, then press it" in the row's description. No simulated Ctrl+C: it would overwrite what the user copied.
