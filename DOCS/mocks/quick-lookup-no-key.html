Notes

  1. Toast, once: when the desktop's global-shortcut service accepts Quick lookup but binds no key (KDE does this: it keeps the suggested Ctrl+Alt+D only as an unticked default), the main window shows this toast once. "Choose a key..." does what Settings' "Change..." does (the desktop's dialog, or KDE's Shortcuts page). Dismissing it, or a key arriving later, hides it for good. Seen in issue #1: KDE stored quick-lookup=none for the snap and nothing told the user.
  2. State in words: "No key" in the warning colour with a mark, replacing the muted "Not set", so colour is not the only signal. The button becomes primary and reads "Choose a key..." in this state only.
  3. Where to look: the hint names the entry as the desktop lists it. KDE lists the snap as snap.omnidict with a blank icon, near the bottom of the list among the system services rather than under Applications, and a native install as Omnidict under Applications (both seen on Plasma, 2026-10-21); the Flatpak's name is still to be checked. Ctrl+Alt+D in the text is the key Omnidict suggests.
